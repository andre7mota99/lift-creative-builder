## 🛠️ How to Deploy to GitHub Pages (Free Public URL)

### Step 1: Create a GitHub Account (if you don't have one)
Go to [github.com](https://github.com) and sign up (free)

### Step 2: Create a New Repository
1. Click the `+` icon (top right) → **New repository**
2. Name it: `lift-creative-builder`
3. Add description: "Interactive guide for high-converting iGaming video ads"
4. Choose **Public** (so anyone can access it)
5. Check "Add a README file"
6. Click **Create repository**

### Step 3: Upload Files
**Option A: Upload via Web (Easiest)**
1. In your repository, click **Add file** → **Upload files**
2. Drag and drop `index.html` and `README.md`
3. Click **Commit changes**

**Option B: Upload via Git (If you know Git)**
```bash
git clone https://github.com/your-username/lift-creative-builder.git
cd lift-creative-builder
# Copy index.html and README.md here
git add .
git commit -m "Add Lift creative builder guide"
git push origin main
```

### Step 4: Enable GitHub Pages
1. Go to your repository **Settings**
2. Click **Pages** (left sidebar)
3. Under "Source", select **Deploy from a branch**
4. Select **main** branch, **/ (root)** folder
5. Click **Save**

### Step 5: Access Your Live Guide
GitHub will show you the URL:
```
https://your-username.github.io/lift-creative-builder/
```

**That's it!** Your guide is now live and publicly accessible. Anyone can visit that URL.

1. **Hook-Story-Offer** — Best for new player acquisition

5. **4U's** — Multi-trigger powerhouse for scaling

7. **Story-Driven** — Emotional connection & brand building

Each framework includes:
